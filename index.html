📖 사용 방법
1
시작하기 버튼을 눌러 팝업 창을 열어요.
팝업 차단이 뜨면 주소창에서 허용해주세요.
2
스테이지의 🐾 이미지 업로드를 눌러 캐릭터 이미지를 넣어요.
PNG 투명 배경 이미지를 추천해요!
3
⚙ 설정에서 이름, 성격, Gemini API 키를 입력해요.
API 키가 있으면 AI가 직접 대사를 만들어줘요.
4
밥주기, 놀아주기, 쓰다듬기로 캐릭터를 돌봐주세요!
방치하면 스탯이 떨어지니 자주 들여다봐요 🐾
🔑 Gemini API 키 발급 방법
1 aistudio.google.com 에 접속해요
2 Google 계정으로 로그인해요
3 왼쪽 메뉴에서 Get API Key 클릭 → Create API Key
4 생성된 키를 복사해서 설정 → 공통 → API 키에 붙여넣기!
💡 Gemini API는 무료로 사용할 수 있어요.
데스크펫은 대사를 미리 모아두는 방식이라 API 호출 횟수가 매우 적어요.
API 키 없이도 기본 대사로 즐길 수 있어요!
🔄 데이터 초기화

처음부터 다시 키우고 싶다면 초기화할 수 있어요.
